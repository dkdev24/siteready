# Contributing

Adding a scanner adapter or a framework fixer is additive — new files under `scanners/` or
`fixers/`+`platforms/`, no changes to what's already shipped.

See [CONTRIBUTING.md](https://github.com/dkdev24/siteready/blob/main/CONTRIBUTING.md) in the repo
for the full interface contract.
